\begin{frame}{Data modality changes the evaluation operation}
\begin{itemize}
  \item \textbf{Tabular}: replace a feature or feature group.
  \item \textbf{Image}: mask a region or superpixel.
  \item \textbf{Text}: remove or replace a token.
  \item \textbf{Time series}: perturb an interval.
  \item \textbf{Graph}: remove a node or edge.
\end{itemize}
The same property can require different operational metrics for different representations.
\end{frame}
